# STILL

STILLは、写真と記事の投稿に特化した、クリエイター向けの多機能プラットフォームです。高品質な写真編集機能と、洗練された記事作成機能を提供します。

## ✨ 主要機能

### 📸 写真投稿
- **高機能カメラ**: リアルタイムフィルター、マニュアルフォーカス、ズームなど、多彩な撮影機能を搭載しています。
- **プロ級の編集ツール**: RAW画像の現像に対応。露出やカラー、シャドウといったプロレベルの調整が可能です。非破壊編集のため、いつでも元の状態に戻せます。

### 📝 記事投稿
- **2つの投稿スタイル**: 事実を伝えるためのシンプルな「ニュース記事」と、ビジュアルを重視した「雑誌記事」の2つの形式でコンテンツを作成できます。
- **直感的なエディタ**: ドラッグ&ドロップ操作で画像を配置したり、テキストを編集したりと、直感的に美しい記事を作成できます。

### 📱 統合フィード
- **コンテンツの発見**: 写真と記事が混在するフィードで、他のクリエイターの作品を閲覧できます。
- **ソーシャル機能**: 気に入った投稿への「いいね」、コメント、クリエイターのフォローが可能です。

### 👤 プロフィール
- **マイページ**: 自分の投稿した写真や記事を一覧で管理・確認できます。
- **プロフィール編集**: プロフィール画像や自己紹介をカスタマイズできます。

## 📂 プロジェクト構造

プロジェクトの主要なコードは `still/` ディレクトリに格納されています。

```
still/
├── Core/              # アプリケーションのコア機能（認証, データモデル, サービス）
│   ├── Auth/
│   ├── DataModels/
│   ├── Repositories/
│   └── Services/
├── Features/          # 主要な機能ごとのUIとViewModel
│   ├── HomeFeed/
│   ├── Camera/
│   ├── PhotoEditor/
│   ├── CreatePost/
│   ├── Profile/
│   └── Settings/
├── Application/       # アプリケーション全体の設定・環境
└── Assets.xcassets/   # アセットファイル
```

## 🚀 セットアップ

1.  **リポジトリをクローン:**
    ```bash
    git clone <repository_url>
    ```
2.  **Supabaseの設定:**
    - SupabaseプロジェクトのURLと `anon` キーを `still/Core/Config/SecureConfig.swift` に設定します。
    - `SecureConfig.swift` はリポジトリに含まれていないため、`SecureConfig.swift.example` を参考に手動で作成してください。

3.  **Xcodeで開く:**
    - `still.xcodeproj` をXcodeで開き、ビルドと実行を行います。
